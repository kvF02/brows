## 架构约束

- Domain 保留与供应商无关的 Profile、会话、能力和编译计划；供应商发现、签名规则、版本读取和进程实现属于 Runtime Adapter。
- 运行时发布者策略按 Provider 固定配置，不从 UI 接受路径、发布者白名单或任意浏览器参数。
- 来源信任与能力通过分别判定：可信二进制仍可能不支持指纹；能力失败不能沿用旧的 Supported 状态。
- 保持生产目录、会话所有权、沙箱和进程树回收约束；测试只创建自有临时环境。
- 每阶段以可审查提交记录实现与测试，真实失败结果保留报告，未覆盖项继续标记。

## P0.1 当前验证

官方 CFT 当前包不满足现有 Authenticode 规则，不登记无签名包。先在全新的 Windows runner 验证预装 Microsoft Edge 的真实签名和现有 MV3 产物加载行为。此时仅增加候选测试，生产仍只接受既有运行时；候选探针通过也不等于完整指纹独立通过。只有具备正向证据，才推进固定 Provider 发现、准入和设置页选择，并执行生产双环境观测。
