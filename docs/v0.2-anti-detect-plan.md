# Brows v0.2 Anti-Detect 扩展方案

> **状态**：Phase 5 等待用户审批（ExitPlanMode）
> **目标**：把 Brows 从"安全简化的多 Profile 隔离浏览器"扩展为"通过 pixelscan.net 中等强度检测的 anti-detect 浏览器"，同时保持现有 v0.1 纪律与 59 单元测试零回归。
> **路线**：Chromium 命令行 + Preferences 文件 + JS hook（MV3 扩展）——不做定制 Chromium 内核。
> **核心元原则**："pixelscan 通过率 > 项目纪律的纯洁性"，但不得以"诚实标注"为代价。

---

## Context

### 为什么做这次扩展

1. **业务需求变化**：用户确认 anti-detect 能力是主要需求，pixelscan.net 通过率是硬指标。
2. **当前架构差距**：v0.1 的 `FingerprintPersona` 枚举只有 `SystemNative` 一项，且 domain `validate()` 强制所有 `preserve_system_*=true`、禁止任何 `locale.timezone` 设置。这等于**架构层面禁止**任何指纹伪装。
3. **纪律约束保留**：domain 层不引新 crate；SystemNative 路径零修改；所有被修改字段必须在 UI 标注"真实修改" vs "声明修改"。

### 关键决策（已与用户确认）

| 项 | 决策 |
|---|---|
| 内核路线 | 轻量（Chromium 命令行 + Preferences + JS hook） |
| 必支持维度 | Navigator/Client Hints、Screen/Window、Canvas/WebGL 熵源、AudioContext |
| 目标检测站 | pixelscan.net（中等强度） |
| 工程预算 | 中型项目，1-2 月一次大版本 |
| 诚实原则 | 每个被修改字段都明确标注 |

### 已知局限性（必须 UI 诚实告知）

- Canvas / WebGL / AudioContext 的**像素层熵源**无法通过 JS hook 修改，仅能修改读取结果——会被 CreepJS 等高强度检测站识别。Pixelscan 中等强度可接受。
- 浏览器内核升级可能 break 某些 hook——建议锁定 Chrome 150 长期支持。
- 固定 fingerprint seed 与"防跨 session 关联"是 trade-off，由用户在 UI 显式选择。

### A.3 一致性约束（TZ ↔ Language）

由于 domain 层不能引 chrono / chrono-tz，**v0.2 在 domain 用 hard-code 区域前缀到 language 前缀的映射表**。实现要点：

- **不接受"全部回退到 en"**——Asia/Tokyo 必须匹配 `ja`，否则日本地区配置会直接放过，pixelscan 的 Timezone/Language 一致性会标红。
- 表只覆盖 region prefix（前缀），不下钻到具体城市。例如 `Asia/Shanghai`、`Asia/Tokyo`、`Asia/Seoul` 全部归到 `Asia`，但允许的 language 前缀表是 `[zh, ja, ko, en]`（亚洲常见）。
- Region → Allowed language prefixes 的映射：

```rust
fn expected_language_prefixes(region: &str) -> &'static [&'static str] {
    match region {
        "Asia" => &["zh", "ja", "ko", "en", "th", "vi", "id", "ms", "hi"],
        "Europe" => &["en", "de", "fr", "es", "it", "nl", "pl", "ru", "sv", "pt"],
        "America" => &["en", "es", "pt", "fr"],
        "Africa" => &["en", "fr", "ar", "sw"],
        "Oceania" => &["en"],
        "Atlantic" => &["en", "pt"],
        _ => &["en"], // 兜底，避免对未知时区完全拒绝
    }
}

fn check_locale_consistency(timezone: &str, accept_languages: &[String]) -> Result<(), DomainError> {
    let region = timezone.split('/').next().unwrap_or("");
    let allowed = expected_language_prefixes(region);
    let matched = accept_languages.iter().any(|lang| {
        let prefix = lang.split(['-', '_']).next().unwrap_or("").to_ascii_lowercase();
        allowed.iter().any(|candidate| *candidate == prefix)
    });
    if !matched {
        return Err(DomainError::InconsistentConfiguration(format!(
            "timezone {timezone} requires one of the language prefixes {allowed:?}"
        )));
    }
    Ok(())
}
```

- **缺失 language 的兜底规则**：如果 profile 完全没填 `accept_languages`，domain 层在 `LocaleConfig::validate` 阶段已经拒绝，这里不重复。
- **单元测试覆盖**：`Asia/Shanghai + zh-CN` 通过、`Asia/Tokyo + zh-CN` 拒绝、`America/New_York + en-US` 通过、`Asia/Shanghai + en-US` 拒绝。

### B.3 PersonaFingerprint 派生器（纯函数）

**新增文件**：`crates/application/src/persona_fingerprint.rs`

```rust
pub struct PersonaFingerprint {
    pub user_agent: String,
    pub platform_string: String,   // navigator.platform 字符串
    pub webgl_vendor_reported: String,
    pub webgl_renderer_reported: String,
    pub hardware_concurrency_reported: u8,
    pub device_memory_reported: f32,
    pub touch_points_reported: u8,
    pub chrome_version: &'static str,  // 仅取版本号用于 UA / Client Hints
}

impl PersonaFingerprint {
    pub fn derive(p: &SeedableNoisePersona) -> Result<Self, DomainError> {
        let mut rng = Splitmix64::new(hash_seed(&p.seed));

        // — Chrome 版本候选池 —
        // 固定到最近发布的几个大版本；候选池需在 Chrome 新版发布 3 个月内更新。
        // 来源：https://chromiumdash.appspot.com/releases
        const CHROME_VERSIONS: &[&str] = &["136", "137", "138", "139", "150"];
        let chrome_version = CHROME_VERSIONS[rng.next_usize(CHROME_VERSIONS.len())];

        // — UA 模板 —
        let (platform_token, platform_string) = match p.platform {
            PlatformKind::Windows => ("Windows NT 10.0; Win64; x64", "Win32"),
            PlatformKind::MacOS   => ("Macintosh; Intel Mac OS X 10_15_7", "MacIntel"),
            PlatformKind::Linux   => ("X11; Linux x86_64", "Linux x86_64"),
        };
        let user_agent = format!(
            "Mozilla/5.0 ({platform_token}) AppleWebKit/537.36 (KHTML, like Gecko) \
             Chrome/{chrome_version}.0.0.0 Safari/537.36"
        );

        // — WebGL 候选池（必须与 platform 自洽）—
        // Windows GPU 候选；同一 vendor + renderer 必须成对出现，不得跨平台混用。
        let (vendor, renderer) = pick_webgl_profile(p.platform, &mut rng, &p.webgl)?;

        Ok(Self {
            user_agent,
            platform_string: platform_string.to_owned(),
            webgl_vendor_reported: vendor,
            webgl_renderer_reported: renderer,
            hardware_concurrency_reported: p.hardware_concurrency.get(),
            device_memory_reported: p.device_memory.reported_f32(),
            touch_points_reported: p.touch_points,
            chrome_version,
        })
    }
}

/// 从结构化候选池中选取与 platform 自洽的 WebGL vendor/renderer 对。
/// 若 profile 的 p.webgl 字段非空（用户手动指定），则直接用；
/// 否则从平台候选池中用 rng 选取。
fn pick_webgl_profile(
    platform: PlatformKind,
    rng: &mut Splitmix64,
    override_: &WebGLProfile,
) -> Result<(String, String), DomainError> {
    if !override_.vendor.is_empty() {
        return Ok((override_.vendor.clone(), override_.unmasked_renderer.clone()));
    }
    // — 候选池 —
    // 每条记录为 (vendor, unmasked_renderer)；仅列真实硬件的已知字符串，不瞎编。
    let pool: &[(&str, &str)] = match platform {
        PlatformKind::Windows => &[
            ("Google Inc. (NVIDIA)",  "ANGLE (NVIDIA, NVIDIA GeForce RTX 3060 Direct3D11 vs_5_0 ps_5_0, D3D11)"),
            ("Google Inc. (NVIDIA)",  "ANGLE (NVIDIA, NVIDIA GeForce GTX 1660 Super Direct3D11 vs_5_0 ps_5_0, D3D11)"),
            ("Google Inc. (Intel)",   "ANGLE (Intel, Intel(R) UHD Graphics 630 Direct3D11 vs_5_0 ps_5_0, D3D11)"),
            ("Google Inc. (Intel)",   "ANGLE (Intel, Intel(R) Iris(R) Xe Graphics Direct3D11 vs_5_0 ps_5_0, D3D11)"),
            ("Google Inc. (AMD)",     "ANGLE (AMD, AMD Radeon RX 6600 XT Direct3D11 vs_5_0 ps_5_0, D3D11)"),
        ],
        PlatformKind::MacOS => &[
            ("Apple Inc.", "Apple M1"),
            ("Apple Inc.", "Apple M2"),
            ("Apple Inc.", "Apple M3"),
            ("Intel Inc.", "Intel Iris Plus Graphics OpenGL Engine"),
        ],
        PlatformKind::Linux => &[
            ("Mesa/X.org", "Mesa Intel(R) UHD Graphics 620 (KBL GT2)"),
            ("NVIDIA Corporation", "NVIDIA GeForce RTX 3060/PCIe/SSE2"),
            ("VMware, Inc.", "SVGA3D; build: RELEASE; LLVM;"),
        ],
    };
    let (v, r) = pool[rng.next_usize(pool.len())];
    Ok((v.to_owned(), r.to_owned()))
}

/// splitmix64 PRNG（纯函数，确定性）
pub struct Splitmix64(u64);
impl Splitmix64 {
    pub fn new(seed: u64) -> Self { Self(seed) }
    pub fn next_u64(&mut self) -> u64 {
        self.0 = self.0.wrapping_add(0x9E3779B97F4A7C15);
        let mut z = self.0;
        z = (z ^ (z >> 30)).wrapping_mul(0xBF58476D1CE4E5B9);
        z = (z ^ (z >> 27)).wrapping_mul(0x94D049BB133111EB);
        z ^ (z >> 31)
    }
    pub fn next_usize(&mut self, len: usize) -> usize {
        (self.next_u64() as usize) % len
    }
}

fn hash_seed(seed: &str) -> u64 {
    // FNV-1a 64-bit，无需依赖任何 crate
    let mut h: u64 = 0xcbf29ce484222325;
    for byte in seed.bytes() {
        h ^= byte as u64;
        h = h.wrapping_mul(0x100000001b3);
    }
    h
}
```

**候选池维护纪律**：
- Chrome 版本池必须只包含仍在安全支持期内的版本（通常最近 6 个大版本）。
- 新增 GPU 字符串必须来源于真实硬件报告，不得捏造。
- 候选池变更必须同步更新 `PersonaFingerprint` 的回归指纹矩阵测试（v0.3 引入）。

  Object.defineProperty(Navigator.prototype, 'languages', { get: () => persona.languages });
  Object.defineProperty(Navigator.prototype, 'plugins', { get: () => buildPluginArray() });

  // P1: navigator.hardwareConcurrency / deviceMemory
  Object.defineProperty(Navigator.prototype, 'hardwareConcurrency', { get: () => persona.hardware_concurrency });
  Object.defineProperty(Navigator.prototype, 'deviceMemory', { get: () => persona.device_memory });

  // P2: iframe.contentWindow 一致性
  // P2: WebGL UNMASKED_VENDOR/RENDERER 字符串层
  const origGetParameter = WebGLRenderingContext.prototype.getParameter;
  WebGLRenderingContext.prototype.getParameter = function(p) {
    if (p === 37445) return persona.webgl_vendor;
    if (p === 37446) return persona.webgl_renderer;
    return origGetParameter.call(this, p);
  };

  // P2 (声明修改): Canvas 噪声（仅在 spoof_canvas=true 时启用，固定 seed PRNG）
  // 真正扰动像素，而非缓存原值——否则 pixelscan 的 canvas hash 检测会发现
  // 两次读取完全一致，反而暴露 hook 存在。
  if (persona.spoof_canvas) {
    const splitmix32 = (s) => () => {
      s |= 0; s = (s + 0x9E3779B9) | 0;
      let t = Math.imul(s ^ (s >>> 16), 0x85EBCA6B);
      t = Math.imul(t ^ (t >>> 13), 0xC2B2AE35);
      return ((t ^ (t >>> 16)) >>> 0);
    };
    const seedInt = splitmix32([...seed].reduce((a, c) => (a * 31 + c.charCodeAt(0)) | 0, 0));
    const origGetImageData = CanvasRenderingContext2D.prototype.getImageData;
    CanvasRenderingContext2D.prototype.getImageData = function(x, y, w, h) {
      const data = origGetImageData.call(this, x, y, w, h);
      // 只在已经显式读过该区域时扰动，避免无谓触发 paint 副作用
      if (this._browsCanvasSeeded) {
        const rng = splitmix32(seedInt() ^ (x * 73856093 ^ y * 19349663 ^ w * 83492791 ^ h * 15485863));
        for (let i = 0; i < data.data.length; i += 4) {
          // LSB 抖动 ±1，肉眼不可见，但 canvas hash 必变
          data.data[i]     ^= (rng() & 1);
          data.data[i + 1] ^= ((rng() >> 1) & 1);
          data.data[i + 2] ^= ((rng() >> 2) & 1);
        }
      } else {
        this._browsCanvasSeeded = true;
      }
      return data;
    };
    // toDataURL 不直接修改——它走 getImageData 链路，上面已覆盖
  }

  // P0: WebRTC IP 泄漏抑制（防止真实 IP 通过 ICE candidate 泄露）
  if (persona.webrtc_policy === 'disable_non_proxied') {

      ProxiedRTC.generateCertificate = OrigRTC.generateCertificate?.bind(OrigRTC);
      window.RTCPeerConnection = ProxiedRTC;
      window.webkitRTCPeerConnection = ProxiedRTC;
    }
  }

  }

impl SeedableNoiseFingerprintRuntime {
    fn materialize_extension(&self, persona: &SeedableNoisePersona) -> PortResult<PathBuf> {
        let hash = sha256_hex(persona.seed.as_bytes());
        let dir = self.extension_root.join(&hash[..16]);
        fs::create_dir_all(&dir)?;
        // 渲染模板 → 写入 manifest.json / content.js / background.js
        let manifest = render_template("manifest.template.json", &vars)?;
        let content = render_template("content.template.js", &vars)?;
        fs::write(dir.join("manifest.json"), manifest)?;
        fs::write(dir.join("content.js"), content)?;
        fs::write(dir.join("background.js"), include_str!("stealth_template/background.template.js"))?;
        Ok(dir)
    }
}

## 风险与回滚

| 风险 | 应对 |
|---|---|
| Chrome 升级导致 stealth 钩子失效 | 锁定 Chrome 150 长期支持；新增版本需跑 Pixelscan 回归 |
| MV3 扩展在某些 Chromium 变体被禁用 | 运行时检测 `--disable-extensions` 状态，警告用户 |
| 用户把 SeedableNoise 用于违反 ToS 场景 | 在 Persona 编辑器顶部保留"诚实告知"banner，明确不承诺绕过风控 |
| seed 冲突（不同用户选了同 seed） | UI 提供随机生成 + 提示"如需差异化请修改 seed" |
| Canvas 噪声被识别 | v0.3 用 NativePersona Runtime 解决；v0.2 接受 Pixelscan 标黄 |
