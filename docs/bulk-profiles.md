# 批量环境管理

环境列表支持逐个勾选或选择当前筛选结果，每批最多 200 个环境。搜索和归档筛选变化后，
隐藏的环境移出选择。批量执行期间禁用选择、筛选及单环境修改，列表状态刷新保留页面与任务状态。

- **批量启动**：按选择顺序提交，沿用核心并发上限及 FIFO 队列；运行中、排队中和归档环境跳过。
- **批量停止**：先取消所选排队票据，再停止所选活动会话，避免被选排队项在停止过程中晋升。
- **批量编辑**：只处理已停止或异常环境；支持追加标签、切换代理或使用系统网络。
  保留每个环境自身的种子、语言、运行时、窗口及其他未修改字段。不重复追加大小写等价的 ASCII 标签，
  不为已经一致的配置产生无效写入。代理选择仅发送既有代理 ID，不复制凭据。

操作依次执行，每个环境独立显示成功、排队、跳过、失败或未执行。部分失败不回滚已成功项；
版本冲突不自动重试覆盖。可停止后续操作，当前已提交操作正常结束；离开页面也会停止尚未提交的项。
这是前端对现有 typed commands 的有界编排，不新增通用批量 IPC、任意脚本接口或原子跨环境事务。

核心 profile_update 为整个修订检查与写入持有停止态预留，运行、排队及备份/迁移等占用中的环境拒绝修改。
UI 的状态筛选不会代替后端锁。UI 开发 mock 同步采用该限制。

回归包括部分失败继续执行、取消后不再提交、先取消队列、逐项修订冲突、标签 UTF-8 限制、
配置不变时跳过，以及真实安装版的批量标签、代理清除与重新绑定、十个启动加一个排队、批量停止和宿主崩溃恢复。
